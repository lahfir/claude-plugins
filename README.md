# lahfir-plugins

Claude Code plugins by [Lahfir](https://github.com/lahfir).

## Install

```
/plugin marketplace add lahfir/claude-plugins
/plugin install delegate@lahfir-plugins
```

## Plugins

| Plugin | What it does |
|---|---|
| [delegate](./delegate) | Picks who runs a task: this session, a sub-agent, or an outside CLI. Detects the harnesses a machine has, keeps an allowlist you control, and asks TypeSafe which allowlisted entry fits. |
